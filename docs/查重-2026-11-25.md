# 注意力博物馆查重（2026-11-25）

## 结论

没有人做过和本馆同样的东西。和本馆相近的项目分成三类，每类只做到本馆的一部分。

第一类是代码合集。规模最大、最接近本馆的是 [External-Attention-pytorch](https://github.com/xmu-xiaoma666/External-Attention-pytorch)：1.2 万星，`model/attention/` 下有 38 个注意力文件，每个模块配论文链接和一张结构图，有中英两份 README。它没有时间线和谱系，也不记录官方仓库的固定提交、许可证和数值核对结果。

第二类是论文清单和综述。按条目数算，最大的是 [Awesome-Transformer-Attention](https://github.com/cmhungsteve/Awesome-Transformer-Attention)，三份 README 合计约 5950 条。它收的是使用视觉 Transformer 和注意力的论文，不是注意力模块本身，也没有代码。

第三类是交互网站。2026 年 8 月到 9 月，一门课程（ERA V5 第 8 课「Modern Attention Variants」）的学员做了至少 10 个注意力时间线网站，其中最多的一个自称 68 个机制。[Sebastian Raschka 的 LLM Architecture Gallery](https://www.sebastianraschka.com/llm-architecture-gallery/) 收了 132 个大模型的结构图，可以两两对比。这两类网站都没有代码，收的是机制或整模型，数量在 25 到 132 之间。

声称「收全」的只有中文社区的即插即用合集，例如「全网最全即插即用模块」。这些合集的公开仓库实际有 107 到 178 个文件，混收卷积、融合和下采样模块，注意力占少数。

本馆独有的是三样东西的组合：一是按模块逐件记录来源类型、固定提交和许可证，二是 343 件有和官方实现的数值核对记录，三是把 2014–2026 年约 660 件放进同一套时间线、谱系和知识图谱，并且中英双语。搜过的项目里，每一样都没有找到第二家。本馆的弱项也写在这里：论文配图目前只有 8 件，谱系只有 31 条边，网站只展示 19 件自己复现的代码，222 件的来源是第三方整理。

## 最接近的 5 个项目

1. **External-Attention-pytorch**。它比我们强在三处：代码打包成 pip 包可以直接用，每个模块都有结构图，1.2 万星说明用户多。它比我们弱在三处：只有 38 个注意力模块，最晚的约在 2022 年，没有许可证、提交和数值核对记录。我们馆里有一部分代码本来就来自这一类仓库，所以它和我们的区别在于有没有「出处记录」，不在于有没有代码。
2. **Awesome-Vision-Attentions 和它的综述**。它比我们强的是分类有一篇 2022 年发表的综述撑着，正文有发展阶段图。它比我们弱的是只到 2022 年、只管视觉、33 个实现是 Jittor 版，不能和 PyTorch 官方版直接对照。
3. **ERA V5 的注意力时间线**。它们比我们强在讲解：每个机制写「解决什么问题、付出什么代价、什么时候选它」，有交互的注意力掩码图和 KV 缓存计算器。[HariniJasti](https://github.com/HariniJasti/Attention_timeline) 还做了「从论文发表到工业采用隔了几个月」的图。它们比我们弱在规模（25 到 68 个）、没有代码、没有出处记录，而且是课程作业，68 个的那一个 README 里还没填上线地址。
4. **LLM Architecture Gallery**。它比我们强在展品卡片：每个模型有统一画法的结构图、事实表、config.json 链接和许可证链接，可以选两个模型对比，每天在更新。它比我们弱的是只收大模型整模型，注意力只是表里的一列。
5. **Papers with Code 的 Methods**。它停止服务前是唯一按方法分类、带使用论文数的公开目录。现在 `paperswithcode.com/methods/category/attention-mechanisms` 302 跳转到 `huggingface.co/papers/trending`（2026-11-25 用 curl 查过）。存档能下载，但有效的注意力方法只有 82 个，年份字段基本是占位值，还混进了 25 行广告。

## 有没有人声称「收全」

- 英文项目里，没有找到声称收全所有注意力模块的。[Awesome-Transformer-Attention](https://github.com/cmhungsteve/Awesome-Transformer-Attention) 自称「ultimately comprehensive paper list」，范围是视觉 Transformer 和注意力论文。[Efficient Attention Survey](https://attention-survey.github.io/) 自称覆盖「nearly all existing efficient attention methods」，范围只是高效注意力，方法表是图片，我没有逐条数。
- 中文项目里，[AI缝合术](https://github.com/AIFengheshu/Plug-play-modules) 写「2025 年全网最全即插即用模块」，公开仓库实际 107 个 .py。[ai 缝合大王](https://github.com/ai-dawang/PlugNPlay-Modules) 写「全网最全最新的即插即用模块：目前进度 70％」，公开仓库实际 178 个 .py。一篇 [CSDN 文章](https://damodev.csdn.net/6a4246a5662f9a54cb85b638.html)（计算机视觉研究院，2025-12-04）自称 265 个模块、其中注意力 50 个，要扫码领取，内容无法查证。B 站「迪哥带你学 CV」的视频 BV1ZzKHzoEWa 标题写 150 个缝合模块。
- 按单个项目里真正可查的注意力条目数排：论文清单最大的是 Awesome-Transformer-Attention（约 5950 条，多数不是模块）。专收注意力模块的清单最大的是 pprp（102 篇）。带代码的合集最大的是 lucidrains（约 90 个仓库）。单一仓库里最大的是 External-Attention-pytorch（38 个）。按这个口径，本馆的 660 件比上面每一个都多。

## 我们有而别人没有的

下面每一条都写明我怎么查的。查的范围是本文末尾「搜索记录」里的全部说法和平台。

1. **逐件的来源类型、固定提交和许可证记录**。我对下载下来的 15 份 README 用正则查过提交哈希链接（`/tree/` 或 `/blob/` 后跟 40 位哈希），命中数都是 0。有许可证字样的只有 nn-field-guide 和 Awesome-Transformer-Attention 第二份 README 各一处，说的都是仓库自己的许可证。LLM Architecture Gallery 按模型链接许可证，这是最接近的做法，但它收的是模型权重的许可证，不是代码。
2. **和官方实现的数值核对**。同一批 README 里，查「numerical、allclose、equivalen、verified、数值」，只在 flash-linear-attention 找到一处，说的是融合实现会降低精度。flash-linear-attention 的 `tests/ops/test_gla.py` 拿 Triton 内核对照仓库自己写的 `naive_recurrent_gla`，不是对照作者原版。WebSearch 查「verified against official implementation numerical equivalence collection」，只找到单篇论文自己的核对，没有合集。
3. **2014–2026 年、跨领域、带代码出处的时间线加谱系加知识图谱**。时间线网站（ERA V5 那一批）没有代码和谱系。有谱系的（LLMsPracticalGuide 的进化树、Neural Network Zoo 的海报）是静态图片，收的是整模型或整类网络。WebSearch 查「knowledge graph visualization of deep learning attention papers lineage」和中文「模型 图鉴 注意力 博物馆 谱系」，都没有找到注意力模块的图谱网站。
4. **「收全了吗」统计页**。本馆按扫描方向列出已收、待收、候选、跳过的条数，并写出每个方向依据哪篇综述。搜过的项目里，只有 ai 缝合大王写了一个「进度 70％」，没有说分母是什么。

「中英双语」不算独有：External-Attention-pytorch 有中英两份 README。

## 值得借鉴的做法

1. **展品页按一个固定格式写机制**。ERA V5 时间线每个机制都回答三个问题：当时卡在什么问题上，这个机制买到什么、付出什么，什么时候该选它。本馆的「一句话机制」可以扩成这三栏，序厅的「注意力简史」也可以按「每一步在省哪一项开销」来串。
2. **两件展品并排对比**。LLM Architecture Gallery 让读者选两个模型看结构差异。本馆可以在展品页加「和谱系上一代对比」，并排放两张论文配图和两段机制说明。
3. **日期规则写明并显示**。[HariniJasti](https://github.com/HariniJasti/Attention_timeline) 规定日期取 arXiv v1 提交日，不取会议年份，每个日期标出来源。本馆已经有 `year_source` 字段，可以在时间线上显示它，并统一规则。同一个仓库还做了「发表到采用的间隔」图，本馆可以用「首次进入官方框架（timm、transformers、fla）的日期」做一张类似的图。
4. **pip 包和统一接口**。External-Attention-pytorch 和 lucidrains 的代码都能一行导入。本馆自己复现的 19 件可以照这个做成一个小包，展品页给一段可复制的调用代码。
5. **使用热度**。Papers with Code 给每个方法标「被多少篇论文使用」。本馆可以从 OpenAlex 或 Semantic Scholar 取被引数，在展厅里做排序选项。
