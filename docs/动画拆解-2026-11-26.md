# 「The Last Boring Slide」动画拆解

2026-11-26。材料在 `prototypes/ref-slide/`。本文只记做法，不搬画面、文案和素材。行号都指 `script3.js`，超长行写成「行号@字符偏移」，例如 `4288@14096` 表示第 4288 行从第 14096 个字符开始。摘录按语句断了行，代码字符本身没改。

## 0. 先看结论

- 整页是一个自写的「演示引擎」，渲染全部在一张 WebGL2 画布上，文字也画在画布上。DOM 只放讲者备注、缩略图总览、帮助、提示和加载条。
- 每个场景是一张「节拍表」加一个 `create()` 工厂。画面是时间的纯函数，所以能随时往前往后跳。
- 「同一张纸」靠两招衔接：转场前一帧被单应变换贴到新场景里那张纸的屏幕四角（portal 转场），或者被当作贴图交给一个折纸模拟器（fold 转场）。新场景用 Canvas 2D 重画同一张图表，接住画面后旧帧淡出。
- 噪声几乎都预先烘焙进贴图：一张 96³ 的 3D Perlin-Worley 体积、一张 512² 的四通道 fbm、一张 256² 的可平铺泡沫与焦散底纹。着色器每像素只查表，不现算多层噪声。
- 声音全部是代码合成的，没有音频文件。
- 页面里没找到 `prefers-reduced-motion` 处理，也没找到显式的可见性暂停。

和你的观察有几处出入，以代码为准：

| 你的描述 | 代码里的情况 |
|---|---|
| 右下角数字是 2、3、21、34… | 是每个节拍表里写死的 `page` 字段。开场是普通页码 1、2、3，改版段落从 4 数到 13，从 tower 起才跳成斐波那契数 21、34、55、89、233、610、1,597、2,584、4,181…，数字带千分位逗号。 |
| 纸越拉越高变成塔 | 塔是 47 张纸组成的风琴折（fanfold），一折一折向上展开，不是拉伸。 |

## 1. 文件和边界

- `body.html`：一张 `<canvas id="stage" data-engine="three.js r187">` 和一个空的 `<div id="ui">`。样式里定义了 `.notes`、`.over`（总览）、`.help`、`.toast`、`.load`（加载条），`body.idle{cursor:none}` 负责闲置时藏鼠标。
- `script0.js`、`script1.js`：宿主运行时。`script0.js` 是 `window.__FRAME_PREAMBLE` 的能力表，`script1.js` 处理导航计时、主题和宿主可见性消息。两者都和动画无关。
- `script2.js`：第 1 到 23 行是 three.js 的 MIT 许可证，第 24 行是一条 356 万字符的赋值语句。
  - `window.__FONTS`：字符 0 到 380763，9 个字体的 data URL（GeistMono、Newsreader 正斜体、Anton、Geist、jbmono700、pixel、unb300、unb800）。
  - `window.__ASSETS`：字符 380764 起，`selectall-earth.jpg`（134 万字符）和 13 张 `thumb-<场景id>.jpg` 缩略图。
  - 它们怎么被用：字体由 `M3()` 用 `FontFace` 加载（`4276@2282`），图片由 `ctx.asset(name)` 取出，缩略图给总览网格做 CSS 背景（`4288@13025`），地球照片给 selectall 场景做贴图（`5404@1035`）。
- `script3.js`：esbuild 打包的单个 IIFE。
  - 第 1 行到 `4225@57870`：压缩过的 three.js r187（第 1、5 行最长，中间是 three.js 的 ShaderChunk 源码）。`4548@~700` 到 `4548@4748` 另嵌了 three.js 的 `BufferGeometryUtils.mergeGeometries`。
  - `4225@57871` 到第 5846 行末尾：作者代码，约 72 万字符。开头是数学工具和缓动表，接着是 GLSL 公共库（第 4226 到 4251 行），然后是引擎、文字系统、音频、13 个场景和 10 种转场。

## 2. 整体架构

### 2.1 场景和转场的数据结构

入口在文件末尾，13 个场景按顺序排成数组，转场按名字放进表里（`5846@2636`）。

```js
C3({createDeck:A3,scenes:[$3,My,Ky,n5,g5,X5,ib,lb,yb,Pb,Bb,Gb,qb],
transitions:{fade:P3,"portal-in":Xb,"portal-out":Yb,fold:$b,wash:Zb,flaps:tw,slam:iw,daybreak:sw,line:aw,tear:lw}
,makeAudio:G3,headless:new URLSearchParams(location.search).has("headless")});
```

13 个场景的 id 依次是 office、tower、boat、loop、swarm、dominoes、calendar、lamp、selectall、aim、futures、pile、questions。每个场景对象长这样（tower，`4432@1120`）：

```js
var My={id:"tower",title:"The real chart",enterWith:"portal-in",hud:{font:"monoMed",color:i=>i.p[3]>.12?"#ffffff":"#243039"}
,beats:[{dur:4,hold:4,delay:1.8,page:"21"},{dur:5,hold:4,page:"34"},{dur:7,hold:4,page:"55"},{dur:9,hold:6,page:"89"}
],notes:[ ...讲者备注... ],create(i){ ... }
```

- `beats`：每个节拍有 `dur`（动画时长，秒）、`delay`（按下后多久开始）、`hold`（自动播放时演完再停多久）、`page`（右下角显示的字）。
- `enterWith`：进入本场景用哪种转场。
- `hud`：右下角数字的字体和颜色，可以是随状态变的函数。
- `create(ctx)` 返回场景实例，约定的方法有 `init`、`enter`、`exit`、`update(s)`、`render(target,s)`、`resize`、`page(s)`、`pointer`，以及给转场用的 `portal:{in,out}` 和 `anchor`。
- 转场是 `{dur, create(ctx)}`，实例的 `render({A,B,p,out,a,b,sa,sb,time})` 拿到旧场景画面 `A`、新场景画面 `B` 和进度 `p`，合成到 `out`。最简单的 fade（`4288@16215`）就是 `mix(texture(tA,vUv),texture(tB,vUv),smoothstep(0.,1.,p))`。

### 2.2 谁来调度

`A3()`（`4288@1774` 起）是调度器。它给每个场景包一层 `class v`，持有状态 `s`（`4288@2468`）：

```js
this.s={t:0,dt:0,beat:0,p:new Array(pt).fill(0),_since:new Array(pt).fill(0),n:pt,enter:1,exit:0,dir:1,mouse:f,view:r,q:1,
at:ht=>this.s.p[ht]*D.beats[ht].dur,
k:(ht,gt,dt,Kt=bt.io3)=>Kt(Ct((this.s.p[ht]*D.beats[ht].dur-gt)/Math.max(1e-4,dt-gt))),
since:ht=>this.s._since[ht]}
```

每帧的流程（`4288@9349`）：`requestAnimationFrame(tt)` → 性能调节 `$()` → 更新 `Et(dt)` → 渲染 `at()`。有转场时，`at()` 把旧场景渲染进目标 `d`、新场景进目标 `p`，交给转场合成到 `x`，再画右下角数字，最后 `present()` 输出到屏幕（`4288@8834`）。

### 2.3 方向键、点击、hash 和场景的关系

- 推进 `advance()`（`4288@5184`）：当前场景还有节拍就 `beat++`，否则 `go(g+1)` 并用下一个场景的 `enterWith` 转场。转场进行中再按一次，转场以 3.5 倍速跑完，并记下「跑完再推进一次」。
- 后退 `back()`（`4288@5395`）：节拍减一，到头就倒着播转场回上一个场景，转场时长取 0.55 倍。
- 键位（`4288@14096`）：`ArrowRight`、`ArrowDown`、空格、`PageDown`、`Enter` 推进，`ArrowLeft`、`ArrowUp`、`PageUp`、`Backspace` 后退，`Home`、`End` 跳首尾，`F` 全屏，`A` 自动播放，`M` 静音，`N` 备注，`P` 备注开新窗，`O` 总览，`?` 或 `H` 帮助，`.` 或 `B` 黑屏。
- 指针（`4288@9819` 到 `4288@10471`）：短按（位移小于 12 px、按住少于 600 ms）推进。横向滑动超过 50 px 时左滑推进、右滑后退。右键 `contextmenu` 后退。场景实现了 `pointer()` 时可以先吃掉事件，例如可拖动的画面。
- hash（`4288@12638` 和 `4288@15077`）：每次移动都用 `history.replaceState` 写成 `#场景` 或 `#场景-节拍`，不新增历史记录。手动改 hash 触发 `hashchange` 后跳转。打开页面时按 hash 决定起点（`4288@16106`）。


### 2.4 右下角的数字

它是幻灯片的「页码」，画在画布上，用 Arial 灰色 `#7f7f7f` 起步（`4288@4089`）。取值顺序是场景的 `page(s)` 方法、节拍的 `page` 字段（`4288@4200`）。数字变化时每个字符从下往上滑入，`out4` 缓动、每字错开 0.06（`4288@4868`）。

office 场景自己算页码（`4315@1174`）：前两个节拍是 1、2，第三个节拍先显示 3，改版开始后按改版序号显示 4 到 13。


之后各场景的 `page` 字段依次是 21、34、55、89（tower），233、610、1,597（boat），2,584、4,181、10,946、75,025（loop），一路到 swarm 的 39,088,169、calendar 的 1.3 × 10^15、lamp 的 8.9 × 10^40、selectall 的 10^80 和 ∞，最后 questions 回到 1。页码本身就是「指数增长」这个主题的旁白。

## 3. 时间线

### 3.1 编排方式

没有用补间库，也没有关键帧数据表。一个节拍内的每个动作都写成「这个节拍开始后第 t0 到 t1 秒，用某个缓动走完 0 到 1」，即 `s.k(节拍, t0, t1, 缓动)`。`s.at(节拍)` 给出节拍内已过去的秒数。场景的 `update(s)` 每帧把这些值算出来，直接写进 uniform 或文字的逐字属性。

office 第三个节拍里的选中框和图表弯曲（`4315@1779` 到 `4315@2482`）就是这样写的：

```js
let V=bt.io3(Te(6.15,7,H))*(Y?1:0);
v.draw(V,0,bt.out2(Te(6.9,7.35,H))*(Y?1:0)),m.set(1060,-200,750,980),m.alpha(Z.k(1,.2,.3)*(H>8.6&&Y?0:1));
...
}else if(H<7.25){let rt=v.tip,U=1060+rt[0],j=190+rt[1],J=bt.io3(Te(5.6,5.95,H));nt=[K(1060,U-34,J), ...
```

一次性的音效用边沿检测，只在向前播放时触发（`4315@643`）：`C=(Z,H,Y,q)=>{H&&!P[Z]&&q.dt>0&&q.dir>0&&Y(),P[Z]=H}`。

### 3.2 缓动函数

缓动表 `bt` 在 `4225@57871` 到 `4225@58730`，输入先夹到 0 到 1。

| 名字 | 公式 |
|---|---|
| `kt`（smoothstep） | x²(3 − 2x) |
| `Fn`（smootherstep） | x³(x(6x − 15) + 10) |
| `lin` | x |
| `in2`、`out2` | x²，1 − (1 − x)² |
| `in3`、`out3` | x³，1 − (1 − x)³ |
| `io3` | x < 0.5 时 4x³，否则 1 − (−2x + 2)³ / 2 |
| `in4`、`out4`、`io4` | x⁴，1 − (1 − x)⁴，x < 0.5 时 8x⁴，否则 1 − (−2x + 2)⁴ / 2 |
| `in5`、`out5` | x⁵，1 − (1 − x)⁵ |
| `inExpo`、`outExpo`、`ioExpo` | 2^(10x − 10)，1 − 2^(−10x)，两段拼接 |
| `outBack(x, s=1.4)` | 1 + (s + 1)(x − 1)³ + s(x − 1)² |
| `inBack(x, s=1.4)` | (s + 1)x³ − s x² |
| `spring(x, f=1.6, d=5)` | 1 − e^(−d·x) cos(2π f x)，x 夹在 0 到 10，按秒传入 |
| `Mr(k, dt)` | 1 − e^(−k·dt)，帧率无关的指数平滑系数 |

场景里还有几个专用曲线：

- loop 场景的 `Mv`（`4731@653`）：x⁴(35 − 84x + 70x² − 20x³)，比 smootherstep 更平的 9 次曲线，用于每次「推进一层」的缩放。
- tower 每张纸展开的 `AA`（`4315@6054`）：前 0.8 段是 `Fn` 和 `in2` 的混合，之后是 1 + 0.085 sin(2.3t) e^(−0.9t) 的衰减回弹，像纸张落定时轻轻弹一下。
- fold 转场每道折痕的 `A`（`5685@1329`）：前 72% 用 smoothstep，之后 1 − 0.05 sin(…) 的小回弹。
- 文字错峰（`4281@4012`）：第 i 个单元的起点 x = i/(n−1)·stagger，局部进度 v = clamp((s − x)/(1 − stagger))。这样不管有多少个字，最后一个字都恰好在 s = 1 时到位。

### 3.3 时长的量级

- 节拍 `dur`：0.5 秒到 25.8 秒。office 第三个节拍 `bA = Ms + 2.6`，按 `To` 表算出约 25.8 秒，里面串了 10 次改版。tower 的节拍是 4、5、7、9 秒，boat 是 4、6、6 秒，loop 是 4、4、4、10 秒。
- 转场：fade 0.7 秒，portal-in 3.2 秒，portal-out 2.8 秒，fold 3.4 秒，wash 2.6 秒，slam 1.9 秒，daybreak 3.4 秒，line 2.4 秒。
- `delay` 一般是 0.9 到 3.1 秒，用来等转场落定再开演。
- 帧间隔 `dt` 被夹在 0 到 0.05 秒（`4288@9349`），切回标签页时画面不会猛跳。

### 3.4 为什么能中途往前往后跳

关键在 `step()`（`4288@3255`）：每个节拍的进度 `p[i]` 是可以双向走的积分量。

```js
step(D){let z=this.s,pt=this.def.beats;z.dt=D,z.t+=D;for(let ht=0;ht<z.n;ht++)if(ht<=z.beat){let gt=pt[ht].delay||0;
z._since[ht]+=D,z._since[ht]>=gt&&(z.p[ht]=Math.min(1,z.p[ht]+D/pt[ht].dur*(ht<z.beat?3:1)))}
else z._since[ht]=0,z.p[ht]=Math.max(0,z.p[ht]-D/pt[ht].dur*2.4);
this.inst.update(z)}
```

- 当前节拍以 1 倍速走向 1。前面没走完的节拍以 3 倍速补完。
- 当前节拍之后的节拍以 2.4 倍速退回 0，所以按「后退」时动画是倒放回去的，不是硬切。
- 跳转 `jump()` 和 `go(...,{beat})`（`4288@5634`、`4288@6097`）直接把目标节拍之前的 `p` 设成 1、`_since` 设成 30 秒，再调 `enter()`。
- 场景的 `update(s)` 只读这些进度，不依赖上一帧的累积状态（boat 的锚链物理是例外，见 5.4）。所以 `test.seek()`（`4288@10840`）能离线把任意场景推到任意时刻，用于生成缩略图。

## 4. 镜头

### 4.1 tower：关键帧加 Hermite 样条

镜头关键帧表 `_a`（`4315@6861` 到 `4315@7598`）按「全局时间」T 排列，每帧有位置、注视点、视角、滚转、跟拍权重。带 `stop:1` 的关键帧切线为 0，镜头在那里停稳。其余关键帧用前后两帧的差分当切线，求值用三次 Hermite（`4315@7740` 到 `4315@8092`）。

```js
,{T:21,x:-14,y:22,z:44,lx:-19.5,ly:-27,lz:6,fov:76,r:0,f:1,stop:1}],rv=["x","y","z","lx","ly","lz","fov","r","f"],
Q3=rv.map(i=>_a.map((t,e)=>{if(t.stop||e===0||e===_a.length-1)return 0;let n=_a[e-1],o=_a[e+1];return(o[i]-n[i])/(o.T-n.T)}));
function oy(i,t){i=Ct(i,0,21);let e=0;for(;e<_a.length-2&&i>_a[e+1].T;)e++;let n=_a[e],o=_a[e+1],s=o.T-n.T,a=Ct((i-n.T)/s),r=a*a,l=r*a;
for(let c=0;c<rv.length;c++){let u=rv[c];t[u]=(2*l-3*r+1)*n[u]+(l-2*r+a)*s*Q3[c][e]+(-2*l+3*r)*o[u]+(l-r)*s*Q3[c][e+1]}
```

- 全局时间是 `Ot=et=>et.p[1]*5+et.p[2]*7+et.p[3]*9`（`4437@346`），即各节拍进度乘时长再累加。镜头因此跟着节拍进度走，倒放时镜头也倒着飞。
- 折线头部的位置 `hv()`（`4315@5945`）另用一套关键帧，切线用调和平均（`ny`，`4315@5219`），保证单调、不超调。
- 叠加的「手持感」（`4437@502` 到 `4437@1139`）：几组不同频率的正弦让位置、注视点和滚转慢慢晃，鼠标位置按距离比例带一点视差。T 大于 18.5 之后晃动幅度变大。
- 入场的推远（`4437@2284`）：在 portal 转场期间，镜头距离在对数空间插值 `Math.exp(K(Math.log(Ft),Math.log(rt.z),St))`，起点距离 `Ft` 恰好让第一张纸铺满屏幕。
- 窄屏适配（`4437@2599`）：宽高比小于 16:9 时按比例放大竖直视角，横向构图不被裁掉。

### 4.2 boat：多组镜位按节拍进度 lerp

boat 的镜头（`4613@2075` 到 `4613@3692`）是几组手写镜位，用 `Q.k(...)` 的进度互相 `lerp`。另有三件事：

- 镜头高度不低于海面加 0.95 m，抬升量用 `1-Math.exp(-3.5*dt)` 平滑。
- 俯仰角用 x / ∛(1 + |x|³) 软限幅（`4613@3469`），镜头不会突然翻转。
- 滚转写进 `R.up`，随时间轻摆。

### 4.3 景深、雾、色调映射和后期

- 景深：tower、boat、loop 都没找到。dominoes 场景（`5053@257`）和另外两处粒子（`5078@113`、第 4232 行附近）用了按深度算的弥散圆 `coc`。
- 雾：tower 用解析的高度指数雾 `fogAmt()`（第 4329 行），雾色 `hazeCol()` 取地平线方向的天空色，远处物体自然溶进天空。还有几张带噪声透明度的竖直「雾卡」（第 4400、4417 行）。boat 用距离雾混天空贴图（第 4533 行），水下用按波长吸收的指数衰减（第 4462 行）。
- 后期 `r.post()`（`4258@895` 到 `4276@1440`），每个场景传自己的参数：
  - 泛光：6 级降采样（13 点滤波，第一级带阈值和亮度压缩），再逐级升采样叠加。
  - 色调映射：AgX 或 ACES 二选一（第 4263 到 4268 行）。
  - 调色：曝光、对比度、饱和度、lift 和 gain、褪色。
  - 镜头效果：径向色差 `uCA`、泛光带红边的 halation、暗角、按帧变化的胶片颗粒（中间调最强）。
- 最终输出 `present()`（`4276@1129`）：叠两个哈希噪声做 ±1/255 的三角抖动，消除渐变色带。纯白像素保持纯白，白底幻灯片因此不发灰。
- tower 的参数（`4437@6218`）：`exposure` 0.8 到 0.88，`bloom:.3`，`threshold:1.6`，`tone:"aces"`，`vignette:.1`，`grain:.022`。
- boat 的参数（`4613@10490`）：`tone:"agx"`，`vignette:.34`，`grain:.03`，`halation:.5`，`ca:.004`。
- tower 还有按镜头速度的运动模糊（第 4419、4420 行）：用上一帧的投影矩阵 `uPrev` 把当前像素的世界位置投回上一帧，沿屏幕位移方向取 11 个样本，采样点加交错梯度噪声抖动。只在镜头快速飞行的时段打开（`4437@3061`）。

### 5.1 白底幻灯片本身就在 WebGL 里

开场的土气幻灯片不是 DOM。

### 5.3 塔：47 张纸的风琴折，在顶点着色器里摆位

- 几何：一张 40×10 分段的平面，实例化 47 次（`4432@4213`，`cv=47`）。
- CPU 每帧调 `r0()`（`4315@6188` 到 `4315@6861`），给每张纸算一个 vec4：底边位置、高度、折角和抖动幅度，打包进 `uS[48]` uniform。纸两张一组（c = 1 + 2l），一张向前折、一张向后折。展开程度用 `AA()` 回弹曲线，后面的纸展开得越来越慢。
- 顶点着色器 `onSheet()`（第 4339 到 4342 行）按折角把每张纸立起来，叠加三组正弦的「纸面起伏」`wob()`，用差分求法线。

- 折线：沿曲线按弧长采样（`Xi`，`4315@4364`），做成 9 段截面的带子网格（`4432@4518`）。带子贴在纸面上，随纸一起起伏。头部 `uHead` 随全局时间前进，「画出来」靠 `step(cv.g,uHead)` 截断。

### 5.4 tower 到 boat：fold 转场是一个真的折纸模拟

- 纸型（`s6()`，`5669@2924` 到 `5669@3929`）：从两块矩形多边形出发，按 8 条折线（`Cc`：cr、cl、tfr、tfl、tbr、tbl、bf、bb，即折纸帽再折船的标准步骤）用 `Ph()` 做多边形裁切（`5669@1826`），再用 `d2()` 把裁下的部分沿折线镜像。每块多边形记下自己经历的折叠序列 `ops`。
- 折叠动画（`5685@1012` 到 `5685@4996`）：每道折线一个绕折痕轴的旋转矩阵，角度按各自的时间窗用 `A()` 推进。每个顶点按自己的 `ops` 顺序依次乘这些矩阵，得到刚性折纸。
- 翻开成船（`5685@2639` 起）：后半段改成 11 个关键点 `jb`，按重心坐标拖动每块多边形，把纸帽撑开成船。
- 着色（`5669@4484` 到 `5684@0`）：
  - 正面印着旧场景的最后一帧（`tA`）。
  - 折痕处画「压痕暗线加亮边」，由 `uCr` 分四组按时间出现。
  - 用 1024² 深度图加 10 点旋转盘采样做软阴影。
  - 背面有纸纤维噪声，印刷在裁切边前停一点。
- 落点（`5685@7292`）：转场结束时纸船的位置、大小和角度等于 boat 场景 `anchor()` 报告的屏幕位置。boat 场景里的纸船网格（`4548@4748` 到 `4548@6942`）由 12 个命名顶点和 14 个三角面组成，每面细分 7 级，鼓起一点，用重心坐标的 `fwidth` 画出折痕。
- 船身纸面除了自己的图表画布（`Vy()`，`4608@203`），还以 9% 混入 tower 最后一帧的快照 `snapshots.tower`（`4613@7864`，`v.uPrev.value=i.snapshots.tower?.09:0`）。
- 锚链用 Verlet 积分加 22 轮距离约束（`c0`，`4437@8406` 到 `4437@9677`），带水中阻尼和触底处理。这是全片少有的带历史状态的部分。

### 5.5 boat 到 loop：wash 转场

wash（`5685@7492` 起）把镜头当成一块玻璃，处理三件事：

- 一道水浪的前沿 `lip()` 斜扫过画面，边缘用 fbm 扰动。
- 退水线 `drain()` 从上往下退。
- 退过的地方留下水流 `rivulets()` 和水珠 `beads()`，水珠各有大小和干掉的时刻，干之前按高度场折射后面的画面。

## 6. 各个画面元素

### 6.1 天空和云（tower）

天空 `sky()`（第 4319 到 4327 行）是解析式。地平线、中天、天顶三种颜色按仰角做两个指数衰减混合，朝太阳的方位角再偏暖。另有三套配色（黎明、白天、高空）按镜头高度混合。太阳用 24、180、2200 三个幂次叠出光晕和日轮。地球曲率由 `uR` 和 `uDip` 算，镜头越高地平线越低，高空还会出现星星（第 4395 行）。

云（第 4379 到 4392 行）是 150 m 到 272 m 之间的一层体积云，用光线步进：

- 步数是 30 或 46，随画质档位变。
- 步长随距离变大，空的区域再放大 1.7 倍。
- 透射率低于 0.012 时提前退出。
- 每个采样点只向太阳方向补 3 次密度采样。

密度只查两张预烘焙的贴图（`4437@1426` 到 `4437@1709`，初始化时逐层渲染）：

- 96³ 的 3D 体积 `gy`（第 4424 到 4428 行）：4 个八度的可平铺 Perlin，加 3 个八度的 Worley。
- 512² 的四通道 fbm `yy`（第 4428 到 4432 行）：每通道 6 个八度。

近处再用高频 Worley「侵蚀」边缘，远处跳过。云在半分辨率下渲染，以纸面所在平面 z = 0 为界分成「纸后」和「纸前」两份，再各用 3×3 模糊上采样合成。逐像素起点用交错梯度噪声抖动，换取少步数下没有条纹。

### 6.2 盐湖地面和倒影（tower）

地面（第 4401 到 4415 行）不是网格。背景着色器对每条视线求它和弯曲地面的交点。

- 湿润表面：法线来自 2D 噪声贴图的 4 次取样，两两反向漂移，所以水膜在缓慢流动。
- 反射：先用 Schlick 式菲涅耳（幂 2.6）反射天空。
- 倒影：纸塔、鸟和小人另渲染一遍到半分辨率目标，顶点着色器把 y 乘 −1（`uMir`，`4437@5773`）。地面再按法线扰动去读这张图，竖直方向做 5 次模糊。镜头高于 160 m 时整套关掉。
- 盐壳：90 m 以下、260 m 以内，用 Voronoi 求边距离（第 4394 行，Inigo Quilez 的边距法）画出多边形盐壳纹。
- 高空：换成低频的「盐、浅水、雾」大色块。
- 远山：用噪声贴图沿方位角查表，得到两层剪影。
- 前景：地面上站着一个 2D SDF 拼出的小人剪影（第 4377、4378 行），会轻轻摇摆。

### 6.3 海面（boat）

- 波浪：两套可平铺的 Gerstner 波谱，46 m 的块 28 列波，5.7 m 的块 34 列波（`Sy()`，`4437@6853`）。振幅按波数的幂律衰减，频率按深水色散 ω = √(gk)。另加 3 列解析涌浪。
- 烘焙：每帧把两套波谱各烘成一张高度、坡度贴图（`Ey`、`_y`，第 4438 到 4447 行）。水平位移用 3 次不动点迭代反求，同时输出雅可比行列式，行列式小的地方就是浪尖，画白沫。
- 海面求交：高度场光线步进 `traceAir()`（第 4486 到 4489 行），最多 92 × `uQ` 步，命中后二分 7 次。
- 着色（第 4508 到 4533 行）：
  - 反射天空：天空先渲染成一张经纬度贴图 `tSky`，按粗糙度取 mip。
  - 太阳高光：指数随粗糙度从 2600 降到 90。
  - 船的倒影：在着色器里对 14 个三角面做光线求交（第 4493 行）。
  - 水体：折射看到水下沙地，浪尖做次表面透光，白沫贴图，远处雾化。
- CPU 镜像：同一套波形另有一份 CPU 实现 `l0.h()`（`4437@7956`），让纸船和镜头贴着浪起伏。

### 6.4 水下焦散（boat）

- 焦散贴图（`zy`、`Iy`，`4548@227` 到 `4548@567`）用「网格面积比」生成：一张网格的顶点按水面坡度偏移（模拟折射后光线的落点），片元着色器输出偏移前后面积之比 `a/b`，光线汇聚的地方就亮。
- 沙地、锚、船底取焦散时（`caustic()`，第 4463 行），把点沿太阳在水中的方向投回水面坐标。两种尺度各取一次，第二次旋转 37°。深度越大取越高的 mip，越深越糊。
- 光柱（`Py`，第 4500 到 4506 行）：沿视线步进 18 步累加焦散贴图，同样用交错梯度噪声抖动。
- 镜头在水下时，用 1.333 的折射率算斯涅耳窗和全反射（第 4536 到 4544 行）。水中还有 900 粒「海雪」（`IA`，`4612@931`），在镜头周围的盒子里循环，不用逐粒更新。
- 镜头正好卡在水面时（`uLens`、`uMen`），按镜片上的水线把画面分成水上水下两半，水线处画一道暗边和一道亮边（第 4546 到 4548 行）。

### 6.5 鸟群（tower）

两群鸟，22 只和 16 只，飞在不同高度（`4432@7390` 到 `4432@7926`）。每只鸟是 6 个顶点、两片三角形翅膀的实例。扇翅、滑翔和翅膀弯曲都在顶点着色器里算（`mv`，`4378@686` 到 `4378@1155`）：

- 扇翅角 `f=sin(t)*(.25+.55*gl)`。
- 滑翔开关 `gl=smoothstep(-.2,.5,sin(...))`，让鸟时扇时滑。
- 翅膀按 `cos(f*x*x)` 弯曲。

鸟群中心在 CPU 上沿李萨如曲线绕圈（`4437@4590`）。鸟只是深色剪影加雾，按镜头高度显隐。

### 6.6 水花粒子（boat）

`Yy()`（`4612@1718` 到 `4612@2686`）建了 8 个粒子系统：落水 900、破水 3600、坠落 1500、船头 900、冲刷 600、气泡 700、漏水 160、海雪 900。

- 粒子都没有 CPU 状态。每粒的随机数存在实例属性里，位置在顶点着色器里由「事件后的时间 τ」解析算出：带阻尼的抛体 p = p₀ + v(1 − e^(−dτ))/d − gτ²（第 4609 到 4611 行）。
- 每粒沿屏幕速度方向拉长，形成水线。
- 一部分粒子是泡沫团（`kind`），半径随时间变大，透明度用噪声贴图打碎。
- 循环系统用 `mod` 让 τ 周期性回绕。

```glsl
vec3 p=p0+v*ex+vec3(0.,-1.,0.)*(3.6*(1.-kind*.75))*tau*tau; vec3 vel=v*exp(-dr*tau)-vec3(0.,7.2*(1.-kind*.75),0.)*tau;
vec4 c=viewMatrix*vec4(p,1.); vec3 vv=mat3(viewMatrix)*vel; float sp=length(vv.xy); vec2 d=sp>1e-3?vv.xy/sp:vec2(0,1);
```

tower 里另有 420 条「速度线」（`by`，第 4432 行开头），在镜头周围的盒子里用 `mod` 回绕，按镜头速度拉成细线，只在快速爬升时出现。

### 6.7 最后的扁平动态图形（loop）

loop 是一条无限缩放的「海报套海报」。

- 结构：12 张 16:9 海报（`Pa`，第 4635 行起），每张是一段 GLSL，用 SDF 画扁平图形，并在某个位置放下一张海报 `child:[x,y,缩放,角度]`。从第 4 张起循环（`Ar`，`4730@1872`）。
- 镜头：每帧把相似变换逐层复合，求出当前层的屏幕变换。层与层之间用三次 Hermite 插值位置、对数缩放和角度（`4745@468` 到 `4745@3177`），缩放速度恒定。
- 缩放运动模糊（第 4740 到 4745 行）：按缩放速度沿对数螺线取 22 个样本，`rot(uTw*t)*v*exp(uRate*t)`。
- 配色：10 个固定色（`wv`，`4730@0`），红 `#ef4129`、蓝 `#1794de`、黄 `#ffc312`、薄荷、粉、群青 `#292ca3`、近黑、纸白 `#f4efe2`、橙、绿。
- 公共库 `m0`（`4613@11136` 到 `4635@0`）：
  - `fil(d)` 是按像素宽度抗锯齿的 SDF 填充。
  - `bed()` 给下一张海报画硬边投影和纸边。
  - `tooth()` 是纸张颗粒，按 `log2(uPx)` 在两个八度之间混合，缩放时颗粒在屏幕上的大小不变。
- 细节层次：海报小到一定程度就混成它的平均色 `uMean`（`mix(c,uMean,smoothstep(.5,1.7,uPx))`），比一个像素还小的直接隐藏（`Rt>1`）。版本标签和彭罗斯拼贴另有显示阈值。
- 彭罗斯拼贴（`$y()`，`4730@226`）：用黄金比做 7 次「瘦、胖三角形」细分，生成菱形网格。菱形按波前依次翻面，翻面是沿自身轴把宽度乘 cos(πt)（第 4737 行）。
- 版本号标签「v1、v2…」：从一张数字图集按位拼出（`4731@2039`、第 4733 行）。底部有一条滚动的彩色色条（第 4743 行）。

## 7. 假编辑器那一段

全部画在 WebGL 画布上，没有 DOM 和 CSS。

- 打字：靠字符串切片按时间截取，`L=(Z,H,Y,q=17)=>Z.slice(0,Math.max(0,Math.floor((Y-H)*q)))`（`4315@643`）。默认每秒 17 个字符。「I can fix it.」每秒 20 个字符。删掉「Agenda」每秒 12 个字符，删掉「This slide is bad.」每秒 34 个字符（`4315@768` 到 `4315@1072`）。
- 节奏表（第三个节拍内的秒数）：
  - 0.85 秒选中标题。
  - 1.9 到 2.5 秒删掉「Agenda」。
  - 2.5 到 4.6 秒打出「This slide is bad.」。
  - 4.75 秒选中项目符号区。
  - 5.35 秒起逐条删除，间隔 0.13 秒，每条一个音高渐升的删除音。
  - 5.6 秒选中图表，6.15 到 7 秒折线弯成指数曲线。
  - 7.3 秒再选中标题，7.4 秒起删掉。
  - 8 秒起打「I can fix it.」。
  - 9.1 秒起进入改版。
- 字符数一变就触发一次 `type` 音效，前提是在向前播放（`4315@1422`）。
- 光标：一个 4×76 的黑色矩形，跟在文字末端。打字和删除的窗口内显示，`Math.sin(H*9)>-.4` 时闪烁，4 秒前常亮（`4315@1949`）。
- 选中框 `SelectBox`：一个 SDF 着色器矩形（`4281@6085` 到 `4287`，类在 `4288@103` 到 `4288@1521`），带四角圆形手柄、底部旋转把手、可选虚线和外发光。出现时用 `outBack(t,2.2)` 弹一下。框在不同目标之间移动时，四个坐标分别插值，再叠一个 `Math.sin(H*7)*3` 的呼吸（`4315@3313`）。

## 8. 性能和兜底

- 像素比和像素预算（`4288@7795` 到 `4288@8163`）：`devicePixelRatio` 上限 2，总像素上限 2560×1600，超出就整体缩小。URL 参数 `?px=` 可以覆盖。
- 按帧时间降级（`4288@9060` 到 `4288@9349`）：
  - 帧时间做指数平均 `rt=rt*.94+W*.06`。
  - 平均超过 21 ms，且距上次调整超过 1.2 秒，内部渲染比例按 1 → 0.84 → 0.7 → 0.58 降一档。
  - 连续 5 秒低于 18.5 ms，且距上次调整超过 6 秒、不在转场中，才升回一档。
  - 同一档最多降 3 次，防止来回抖。
  - 画质档位同时传给着色器：云的步数、海面步进次数随 `q` 变（`4437@6026`、`4613@10239`）。

```js
let rt=0,U=0,j=0,J=[1,.84,.7,.58],Pt=[0,0,0,0];function $(W){if(n||document.hidden||W>200)return;
rt=rt*.94+W*.06,U+=W,j=W<18.5?j+W:Math.max(0,j-W*12);
let D=J.indexOf(_);rt>21&&U>1200?D<J.length-1&&(Pt[D]++,_=J[D+1],U=j=0,rt=14,Mt()):D>0&&j>5e3&&U>6e3&&Pt[D-1]<3&&!b&&(_=J[D-1],U=j=0,Mt())}
```

- 可见性：没找到 `visibilitychange` 暂停。标签页隐藏时只是不计入性能统计，并依赖浏览器自己暂停 `requestAnimationFrame`。`dt` 上限 0.05 秒，回到页面不跳帧。
- `prefers-reduced-motion`：没找到（`matchMedia`、`prefers` 都是 0 处）。
- WebGL 不可用（`4288@15459` 到 `4288@15562`）：初始化抛错就在 `#ui` 里放一行提示「需要 WebGL 2」，没有降级版本。
- 资源预热：
  - `warmAll()`（`4288@7447`）在加载条后面把每个场景的每个节拍各渲染一次，把每种转场按进度 0.2、0.5、0.8 各渲染一次，逼着色器提前编译、贴图提前上传。`?quick` 跳过预热。
  - 播放中（`4288@6759` 到 `4288@7191`）：离当前场景超过 1 的场景，渲染目标缩到 2×2（`park`）以释放显存。后面 2 个场景用 `setTimeout` 分别延后 300、600 ms 预热。
  - 离开场景时把最后一帧存成 640×360 快照（`4288@7667`），后面的场景拿来当纸面印刷或回顾墙。
- 其他：鼠标 2.2 秒不动就加 `idle` 类藏起光标（`4288@14911`）。`?headless` 打开 `preserveDrawingBuffer`，供离线截图。

## 10. 声音

有声音，而且全部是程序合成的。

- 采样库 `Sr`（`4288@21042` 起）：tick、click、type、select、delete、whoosh、thud、snap、pop、drip、creak、paper、domino、splash、riser、boom、shimmer 等。每种有 1 到 6 个变体，用固定种子的随机数在 48 kHz 下离线算出。
- 合成手段：
  - 衰减正弦振子 `We()`，用旋转递推实现。
  - 状态变量滤波器 `Pi`（梯形积分式）处理噪声。
  - 扫频 `ii()`。
- `k3()` 另外生成持续音垫、拨弦、马林巴、玻璃、人声，以及两条混响脉冲响应（hall 4.6 秒、room 0.55 秒）。`D3()` 按优先级在后台分片计算（`4288@37655` 到 `4288@38764`）。
- 播放引擎 `U3()`（`4288@40393` 起）：用 WebAudio 的增益总线和两个 `ConvolverNode` 混响。场景用 `audio.param("wind"|"water"|"tension"|"speed"|"hum", 值)` 推动环境音床。环境音床由粉红噪声和棕色噪声经滤波得到（`4288@75372` 到 `4288@76438`）。
- 激活：首次按键或指针按下时 `unlock()` 恢复 `AudioContext`（`4288@10087`、`4288@14096`）。`M` 键静音。

## 11. 可以直接搬到普通静态网站上的通用手法

我们的网站只有 SVG 和 DOM，没有 WebGL。每条写清手法、它在参考页的位置、在博物馆里怎么做。

1. **把动画写成时间的纯函数，用节拍表驱动。**
   - 参考页：`beats` 加 `s.k(节拍,t0,t1,缓动)`（`4288@2468`），`step()` 双向推进（`4288@3255`）。
   - 博物馆：写一个不到 100 行的小调度器，每个展室或玫瑰窗开场是一张节拍表。`requestAnimationFrame` 里算出进度，写进 CSS 自定义属性（`el.style.setProperty('--p', v)`）或 SVG 属性。CSS 只写 `transform: translateY(calc((1 - var(--p)) * 40px))` 这类式子。「后退」时进度以 2.4 倍速倒放，不用另写退场动画。

2. **一张缓动表，加帧率无关的指数平滑。**
   - 参考页：`bt` 表（`4225@57871`），鼠标视差用 `Mr(5,dt)=1-exp(-5*dt)`（`4288@8163`）。
   - 博物馆：把表抄成 JS 函数（公式见 3.2），CSS 那边用对应的 `cubic-bezier`。玫瑰窗跟随鼠标的轻微视差，用 `x += (tx - x) * (1 - Math.exp(-5 * dt))`，在 60 Hz 和 120 Hz 屏上手感一致。

3. **关键帧镜头，用 Hermite 样条，停点切线为 0。**
   - 参考页：tower 的 `_a` 表和 `oy()`（`4315@6861` 到 `4315@8092`）。
   - 博物馆：SVG 的「镜头」就是 `viewBox` 的 x、y、宽、高。首页可以从整扇玫瑰窗飞到某一片花瓣，再飞到某扇尖拱窗。关键帧带 `stop:1` 的地方停稳，其余地方平滑穿过。插值对缩放量取对数再插，推近时速度均匀（参考页 `4437@2284` 的做法）。

4. **「同一张纸」的衔接：新旧两套画法在第一帧对齐，再交叉淡出。**
   - 参考页：portal 转场把旧帧贴到新场景纸张的屏幕四角（`5669@749`），fold 转场让纸船落到 `anchor()` 报告的位置（`5685@7292`）。
   - 博物馆：点画框里的论文图时用 FLIP。先量出缩略图的 `getBoundingClientRect()`，展签里的大图先摆到这个位置，再用 `transform` 动画移到终点。展室之间可以用 View Transitions API，给同一件展品的图设相同的 `view-transition-name`，不支持的浏览器直接跳页。

5. **逐字、逐词错峰入场，用归一化的错峰公式。**
   - 参考页：文字 `show()` 的 rise、blur、type、fade、scatter、track、drop 七种（`4281@3879` 到 `4281@4904`）。
   - 博物馆：标题拆成 `<span>`。第 i 个的延迟取 i/(n−1)·stagger·总时长，单个时长取 (1 − stagger)·总时长，最后一个字准时到位。「rise」配外层 `overflow:hidden` 做裁切，「blur」用 `filter: blur()` 从大到 0。展签标题可以用 rise，展品编号可以用 blur。

6. **一个参数化的遮罩库做转场。**
   - 参考页：9 种遮罩共用一个 `cov(uv,p)`（`4303@966` 到 `4315@109`）。
   - 博物馆：用 SVG `<mask>` 或 CSS `clip-path` 实现同样的形状，只用一个进度变量驱动。扇形擦除（mode 6）和圆形光圈（mode 2）很适合圆形的玫瑰窗，可以用 `clip-path: circle()` 或一个按进度改 `stroke-dashoffset` 的粗描边圆。百叶窗（mode 3）适合尖拱窗格。

7. **假编辑器式的打字：按每秒字数切片，光标只在空闲时闪烁。**
   - 参考页：`L()` 和光标逻辑（`4315@643`、`4315@1949`）。
   - 博物馆：展签打开时，展品编号或一句馆长按语按 17 字每秒逐字出现。光标是一个 `<span>` 竖条，打字时常亮、停下后闪烁。中文按字计，速度可以降到每秒 8 到 10 字。正文不要用这个效果，读者要能立刻读到全文。

8. **细节层次：小到看不清就换平均色，小于一个像素就不画。**
   - 参考页：loop 的 `uMean` 混合和 `Rt>1` 剔除（`4745@1226`、第 4635 行）。
   - 博物馆：3400 条路径的玫瑰窗，整窗视图下把每个花瓣组换成一条填平均色的轮廓路径，或者换成一张预先栅格化的 WebP。推近到某一组时再换成真实路径。缩放时给细节层加 `opacity` 过渡，两层叠着淡入淡出。

9. **按屏幕尺寸固定的纸纹和抖动。**
   - 参考页：loop 的 `tooth()` 按缩放混合两个八度（第 4634 行），`present()` 做 ±1/255 的抖动（`4276@1129`）。
   - 博物馆：羊皮纸或石墙底纹用一张小的平铺噪声 PNG，`background-attachment: fixed`，或者放在不随 `viewBox` 缩放的层上，推近玫瑰窗时纹理不跟着放大。深色哥特背景的大面积渐变容易出色带，叠一层 2% 透明度的噪声图就能消掉。

10. **按帧时间自动降级，带迟滞。**
    - 参考页：`$()` 调节器（`4288@9060`）。
    - 博物馆：用 `requestAnimationFrame` 量帧时间，做 0.94/0.06 的指数平均。超过 21 ms 就依次关掉代价高的效果：SVG `filter`（发光、模糊）、`backdrop-filter`、同时动画的路径数。连续 5 秒低于 18.5 ms 再恢复一档，同档最多降 3 次。

11. **预热下一个、释放远处的。**
    - 参考页：`warmAll()` 和 `park()`（`4288@7447`、`4288@6759`）。
    - 博物馆：进入展室后，用 `<link rel="prefetch">` 取相邻展室的页面和首图。点开展签前先 `await img.decode()`，滑入动画不会因解码掉帧。离开视口的大 SVG 设 `content-visibility: auto`。

12. **地址记录场景和节拍，键盘全可操作。**
    - 参考页：`history.replaceState` 写 `#场景-节拍`，`hashchange` 反向跳转，方向键、空格、`Home`、`End`、`O` 总览（`4288@12638`、`4288@14096`）。
    - 博物馆：展签打开时把地址改成 `#展品id`，用 `replaceState` 不污染返回键。刷新或分享链接能直接打开同一张展签。左右方向键在同一展室的展品间切换，`Esc` 关展签。

13. **落定时的小回弹。**
    - 参考页：纸张展开的 `AA()` 回弹 1 + 0.085 sin(2.3t) e^(−0.9t)（`4315@6054`），选中框的 `outBack(t,2.2)`（`4288@1258`）。
    - 博物馆：展签从右侧滑出时，最后 20% 的时间用一次幅度 2% 到 3% 的衰减回弹，像纸卡被放到桌上。CSS 可以用 `linear()` 缓动函数写出这条曲线。

参考页缺的两件事，博物馆要补上：

- 读取 `prefers-reduced-motion: reduce`。命中时，节拍调度器直接把进度设为 1，FLIP 和遮罩转场换成 150 ms 的淡入淡出，打字效果直接显示全文。
- 监听 `visibilitychange`，隐藏时停掉调度器，回来时重置帧计时。

## 12. 读了什么、没读什么

- 逐段读了：引擎和导航（第 4288 行前 17000 字符）、文字系统、后期、GLSL 公共库，以及 office、tower、boat、loop 四个场景和 portal、fold、wash 三种转场。音频只读了结构和名单，没逐个读合成配方。
