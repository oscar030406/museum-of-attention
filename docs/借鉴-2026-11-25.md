# 注意力博物馆借鉴报告

2026-11-25。比较了 11 个对象。备料顺序为论文引用、并排对比、可查日期、注意力掩码和论文图放大。引用按论文记，结构对比按展品记。全馆浏览和导览都可以调用这五个零件。

## 拆解记录

开源项目看入口、数据文件、锁文件和许可证。闭源网站用浏览器运行记录核对界面、操作结果和网络响应。原始材料和操作参数在 `curation/cache/rea/`，以下文件名以该目录为准。只核实能从页面或源码查到的库。部署产物没有版本标记时，库版本记为未核实。

### 1. External-Attention-pytorch

读者在同一份 README 找到论文、模块图、代码入口和调用示例。目录 `model/attention/` 按模块放实现。以 SE 为例，文档把图和输入输出形状放在示例附近，读者可以从图直接找到实现。项目依赖 PyTorch（BSD-3-Clause），仓库的 `setup.py` 没有固定 PyTorch 版本。仓库 `LICENSE` 写 MIT，但同一版本的 `setup.py` 为 fighingcv 1.0.0 填了 Apache 分类，两个声明有差异。证据在 `sources/external-*`。馆里可保留图、论文、代码出处之间的短路径。代码包和经第三方转引的图片放在原处，因为馆内已有逐件来源记录，且图片权利要按原论文核对。[模块目录](https://github.com/xmu-xiaoma666/External-Attention-pytorch/tree/master/model/attention) · [许可证](https://github.com/xmu-xiaoma666/External-Attention-pytorch/blob/master/LICENSE) · [打包声明](https://github.com/xmu-xiaoma666/External-Attention-pytorch/blob/master/setup.py)

### 2. ERA V5 注意力时间线

HariniJasti 的读者可按家族筛时间线，点节点读机制、取舍和日期出处。页尾另列日期类型和证据，全文还区分提出和采用。机制、家族、日期、核对说明分在 `js/data.js`，交互在 `app.js`，Canvas 小图在 `viz.js`。站点是原生 JS，仓库 MIT，锁文件的 Playwright 1.62.1（Apache-2.0）只用于开发。另一个课程项目 TEJASKUMAR-REDDY-J 把 arXiv 核对口径写进 README。馆里可让来访者直接查 arXiv 首次提交日，并以一个可操作的掩码示意图解释全看、只回看和窗口回看的差别。采用滞后和面向生产的推荐等收录标准定好后再做，否则容易把不同时间事件放进一列。[HariniJasti 源码](https://github.com/HariniJasti/Attention_timeline) · [TEJASKUMAR-REDDY-J 的核对方法](https://github.com/TEJASKUMAR-REDDY-J/attention-timeline)

### 3. Papers with Code 方法页存档

原方法页入口已跳转。存档保留方法名、全名、论文、源码、分类和 `num_papers`，可从类目找方法，再回原论文。数据卡和浏览器样本都显示这是 Parquet 快照。分类由区域和集合组成，一条方法可以归入多类。数据为 CC BY-SA 4.0，其原站前端库和版本无法从存档核实。馆里可借鉴「一件展品属于多个主题」和「把计数的名字说清楚」。不导入快照或拿它补日期。年份列大量填 2000，`num_papers` 的统计范围也与馆内引用不同。证据在 `verified-pwc-archive.json` 和 `sources/pwc-card.md`。[存档与字段](https://huggingface.co/datasets/pwc-archive/methods) · [原类目入口](https://paperswithcode.com/methods/category/attention-mechanisms)

### 4. LLM Architecture Gallery

读者能选两件模型，在同一行对照注意力模块、规模和其他配置。交换按钮把左右顺序写回 URL，刷新或转发可恢复这组对照。运行记录中先选 GLM-5.4 与 Inkling 2 Mini，再交换，结果和 URL 都改变。页面以模型别名标记每件展品，并列面板把图、事实字段和回到原卡片的链接分开。页面加载原站 `gallery.js?v=20261123-6`。这是网页资源版本，浏览器记录未确认可复用的图库或页面许可证。馆里可自行做按展品 ID 恢复的对照、互换、同项对齐和缺值。模型榜单、订阅入口和其余页面结构不进入对照页。证据在 `verified-gallery.json`。[对照工具](https://sebastianraschka.com/llm-architecture-gallery/)

### 5. Transformer Explainer

读者从相同输入进入模型，点开注意力热图，再沿计算过程看分数、掩码、权重和输出。推理和示意由浏览器驱动，页面把 tokenizer、张量和界面状态分开。锁文件核实 Svelte 5.53.5、SvelteKit 2.53.3、ONNX Runtime Web 1.23.0（均 MIT）、D3 7.9.0（ISC）和 Transformers.js 2.17.2（Apache-2.0）。项目 MIT。馆里只需用固定分数展示一步软最大值和被遮住的位置，原生表格和少量计算即可。整套 GPT-2 推理和生成会增加权重下载，也会把导览的历史问题变成生成演示。证据在 `sources/explainer-*`。[项目及锁文件](https://github.com/poloclub/transformer-explainer) · [演示](https://poloclub.github.io/transformer-explainer/)

### 6. LLM Visualization

读者沿同一套模型坐标，从整网到一个张量，再逐步看矩阵里的数怎样流动。仓库把讲解步骤、模型布局和绘制组件分开，页面能保持相同的矩阵含义。源码主线清单固定 Next.js 16.3.0、React 19.2.8（MIT）和 d3-color 3.1.0（ISC），绘图用 WebGL，项目 MIT。馆里可让同一行分数在切换不同掩码时保持不变，让变化只来自可见位置。全模型三维浏览和专用绘图代码成本偏高，图谱页也已经覆盖空间浏览。证据在 `sources/llm-*`。[项目](https://github.com/bbycroft/llm-viz) · [演示](https://bbycroft.net/llm)

### 7. Distill《Zoom In》

读者从文章中的三个主张进入一个个可检查的例子。文章把小标题、图和相邻文字绑定，读者在原地看到同一个论点的图解和限定。页面数据由文章段落、图实例和引文组成。运行记录确认 Distill template v2 和 Web Components polyfill 1.0.17（BSD-3-Clause），模板精确版本和页面各图的代码许可没有从这次记录核实。馆里可把掩码实验放在讨论计算范围的展室旁，并用文中链接回证据。长篇连滚和依赖外站脚本的排版不进入原型。证据在 `verified-distill-circuits.json`。[文章](https://distill.pub/2020/circuits/zoom-in/) · [Polyfill 版本](https://www.npmjs.com/package/@webcomponents/webcomponentsjs/v/1.0.17)

### 8. Connected Papers

从《Attention Is All You Need》进入，读者看到中央图、论文短表和选中论文的资料区。图页接收以论文 ID 为键的版本与图数据，运行记录中这两类请求都返回 200。官方说明用共被引和书目耦合算相似度，然后用力导向布图。这里的连线含义是相似，论文间直接引用需要原始引用数据。页面 DOM 可确认 Vue 和 vue-slider-component（各自上游为 MIT），部署版本和绘图库未核实。官方说明所用 Semantic Scholar 语料当时标 ODC-BY，馆里改用 OpenAlex CC0 的 `referenced_works`。保留先选一篇、展开一跳、查看两端出处的路径。省掉相似度推边、登录和大范围聚类，馆内纸本证据能回答这次的历史问题。证据在 `verified-connected-live.json` 和 `verified-connected-about.json`。[关系图](https://www.connectedpapers.com/main/204e3073870fae3d05bcbc2f6a8e263d9b72e776/Attention-Is-All-You-Need/graph) · [方法](https://www.connectedpapers.com/about) · [OpenAlex 数据许可](https://help.openalex.org/api/)

### 9. 大都会艺术博物馆

读者从《神奈川冲浪里》的大图进入展签，再展开作品详情。作品下方的同类作品和文章分别回答「还能看什么」和「这件为何重要」。Heilbrunn 时间线把年代分期和专题文章连起来，读者可以绕过完整馆藏列表。公开 API 用 objectID 取作品，把图片、权利、年代和作者分成字段。运行记录在 `verified-met-wave.json`、`verified-met-time.json`，API 样本在 `sources/met-api.json`。运行路径可辨认 Next.js（MIT），其版本和图像组件未核实。馆里可让展签回到相应展室并保留上下文，已具备导览入口，后续重点是用现成分期连接日期查询。捐赠、商店和体量很大的相关推荐无需搬入。[展品](https://www.metmuseum.org/art/collection/search/45434) · [时间线](https://www.metmuseum.org/toah/) · [馆藏 API](https://metmuseum.github.io/)

### 10. 荷兰国立博物馆

读者在《夜巡》页可操作放大、缩小和适应画面，也可展开档案，再按作者、材料或具名关系探索。档案给固定馆藏号和永久 URL。搜索服务用 Linked Art 格式组织记录，图像网络记录含 IIIF 区域与尺寸请求。前端的实际图像库和版本无可核实元数据。馆里的静态 WebP 可用 OpenSeadragon 5.0.1（BSD-3-Clause）实现平移、复位、键盘和触屏缩放，直接读本地图。分块图服务器和下载许可流程不适合小幅论文图。证据在 `verified-rijks-watch.json`，放大按钮的补测未取得放大后的画面，本次只把按钮及图像请求列为观察结果。[展品](https://www.rijksmuseum.nl/en/collection/object/The-Night-Watch-Militia-Company-of-District-II-under-the-Command-of-Captain-Frans-Banninck-Cocq--3137deb45cd7765f9a76084a16c99544) · [数据格式](https://data.rijksmuseum.nl/docs/search/) · [OpenSeadragon](https://www.npmjs.com/package/openseadragon/v/5.0.1)

### 11. V&A

「墙纸」主题页先给历史概述、专题文章和馆藏代表作。点击代表作进入对象页，读者可继续读相关主题、展开对象详情和浏览同类展品。代表作链接用 O 编号，API 的集合、作品以及 IIIF 图片各有接口。运行记录确认主题页链接能打开中国墙纸展品 O76937，展品页显示拓展阅读和详情。记录里只核实了站点自己的对象脚本，前端库和版本未核实。馆里可让每个展室给读者一条带当前主题的馆藏入口，并给展签提供返程。商业印制、图库申请和泛同类列表省去，馆里已有按展厅检索。证据在 `verified-vam-wallpaper.json`、`verified-vam-highlight.json`。[主题](https://www.vam.ac.uk/collections/wallpaper) · [展品](https://collections.vam.ac.uk/item/O76937/) · [馆藏数据](https://developers.vam.ac.uk/)

## 候选排序

前五项进入备料。估时以独立原型、数据检查和浏览器验证为范围。

| 排序 | 功能 | 来自 | 来访者能做什么 | 实现及许可 | 工量 | 风险 |
|---|---|---|---|---|---|---|
| 1 | 带出处的馆内引用 | Connected Papers、Papers with Code、OpenAlex | 从一篇论文查它引用的馆内论文，以及引用它的馆内论文 | 直接复用 OpenAlex CC0 引用数据。原生 JS 展示一跳，沿用策展谱系 | 1 天 | 数据库漏收和合并误差。只按 DOI 或 arXiv DOI 匹配，计入覆盖率 |
| 2 | 两件展品并排对比 | LLM Architecture Gallery、External-Attention-pytorch | 同时看两幅原图和对应信息，交换两边并分享链接 | 原生 JS 和馆内数据 | 半天 | 图、简介和许可证可能缺项。显示实际缺项 |
| 3 | 可查的论文日期 | ERA V5、大都会 | 核对版本顺序，理解论文年份和首次提交的差别 | DataCite 记录中的 arXiv v1 日期事实。原生 JS，保留原有年份 | 半天 | 提交日、发布时间、会议日期口径不同。显示日期类型、原文及未核实状态 |
| 4 | 注意力掩码小实验 | Transformer Explainer、ERA V5、Distill、LLM Visualization | 改变可见范围，观察同一行注意力权重怎样重新分配 | 原生表格和 softmax 教学数据 | 半天 | 易误以为掩码能描述所有机制。写明示例范围 |
| 5 | 放大论文结构图 | 荷兰国立博物馆 | 用鼠标、触屏或键盘看清模块连线和字母 | 直接引入 OpenSeadragon 5.0.1（BSD-3-Clause） | 半天 | 小图放大后仍受分辨率限制。保留论文链接 |
| 6 | 主题入口和展签返程 | V&A、大都会 | 从任何展签回到所在展室，再找同主题展品 | 原生路由和 `story.chapters` | 约两小时 | 导览和展签已有部分入口，等馆长统一路径时合并 |
| 7 | 首次采用时间 | ERA V5 | 分清机制何时提出、何时进入框架 | 按公开版本记录单独标注，原生 JS | 1 天以上 | 「采用」定义及框架覆盖偏差，先从已核对提交试做 |
| 8 | 注解式代码浏览 | External-Attention-pytorch、Distill | 从图中一步跳到可运行代码的对应行 | 原生 HTML，沿用馆内自产复现，逐段标证据 | 数天 | 对齐需要逐件校验，且许多展品只有外部代码链接 |

OpenAlex 的引用箭头按「引用的论文 → 被引的论文」记录。馆内一篇论文有多个展品时共享一个论文节点。论文未能匹配、两份标识指向不同作品、或结果没有馆内引用时，数据保留这些情况供读者区分。论文引用与馆长记载的承继关系各自保留证据。

## 备料验收

2026-11-25 的馆藏快照有 773 件展品。OpenAlex 按标识匹配了 330 件展品，对应 328 篇论文和 2,095 条馆内引用。另有 268 件未命中、166 件没有这两种标识，9 件的两个标识返回不同作品。馆内原有策展边在此次核对时有 36 条。馆藏收集期间从查重时的 31 条增到了 36 条，本次原型沿用原生成规则。

用 OpenAlex 的 `referenced_works` 核对了 MHA 对 Bahdanau 注意力论文的引用。同一引用可以在 MHA 论文参考文献查到。DataCite 返回馆内 589 个 arXiv 编号的 v1 提交日。抽查 MHA，arXiv 给出的提交日同为 2017-06-12。[OpenAlex 字段](https://api.openalex.org/works/W2626778328?select=id,referenced_works) · [MHA 原文和参考文献](https://arxiv.org/html/1706.03762) · [arXiv v1](https://arxiv.org/abs/1706.03762v1)
