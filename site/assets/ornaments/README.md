# 公版纹样

这十个透明底 SVG 各有一个填充路径，颜色为 `#362C25`。可用 `<img>` 直接放到浅色底上。内联到页面时，可以把 `fill` 换成 `currentColor`。角花以左上为原向，其余三角可镜像。

坐标来自长边为 850 px 的扫描页，原点在左上角。页数从 PDF 的第一页开始计数。裁图转为单色后沿轮廓描边，去掉纸底和细碎斑点。每个文件的原书和裁区如下。
